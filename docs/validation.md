# 自管理验收

本仓库用已安装的 agent-docs 生成根目录和文档目录入口、项目维护技能、检查工具及决策规则，再由 Agent 当轮读取四部分规则后编写 README、架构与开发文档。验收同时检查可复现行为和语义；通过结构检查不代表所有文字正确。

## 可复现行为

按 [开发流程](development.md#执行检查) 运行测试与检查器，可以验证基础初始化保护，以及项目自身的源副本一致性和分发文档引用。测试使用临时项目进行负向检查：修改消费者规则或引入不存在的分发引用必须失败；缺少或过期的投递记录不能通过初始化验收。

对本仓库再次运行 `agent-docs/scripts/bootstrap.py --root . --apply` 应返回 `existing-materials-preserved`。验收比较运行前后维护文件的摘要，确认没有重新覆盖已经写好的文档和指令。新增或调整规则后，先重新激活对应部分，再运行 `finish`。

## 内容复核

README 负责安装和使用；架构文档解释分发源、消费者、状态和检查边界；开发文档负责操作步骤。完整写作规则仍由项目技能维护，三份文档通过链接引用。决策记录保存本仓库采用源副本一致性检查的理由及代价。

复核保留了容易被简化丢失的限制：bootstrap 的异常恢复不是中断安全事务；重复初始化不是升级；投递摘要无法证明当前轮次或理解；归档哈希只有结合可信基线才能发现协调篡改。这些事实分别由实现和负向测试支持。

规则及内容均可从仓库独立读取，不要求访问原聊天、全局技能目录、DSH 仓库或本机历史试用文件。精确命令结果、投递和复核记录位于被忽略的本地工作状态；正式文档不把本机路径作为可移植引用。

## 未覆盖部分

未验证所有 Markdown 渲染器、链接片段、跨平台路径行为、断电恢复或自动化语义判定。原生 ADR 语法继续由项目约定和人工复核负责。本仓库没有历史归档文件；归档不变性通过临时 Git 仓库中的测试验证，不声称已有生产归档基线。
