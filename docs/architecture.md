# 架构与事实归属

agent-docs 将文档工作流、可复制材料和确定性检查组合成一个技能。Agent 负责理解项目与编写内容；Python 工具负责路径预检、复制和可机械验证的约束。分发包可离开这个仓库独立工作，目标项目的维护材料也可离开全局安装继续使用。

## 源、消费者与项目内容

不同位置具有明确职责。修改时先找到事实的所有者，再更新需要随之变化的消费者。

| 位置 | 职责 |
| --- | --- |
| `agent-docs/SKILL.md` | 全局任务路由、作用范围和当轮读取要求 |
| `agent-docs/references/initialize.md` | 初始化、激活和验收操作 |
| `agent-docs/assets/project/` | 可分发的项目工作流、参考资料、检查器和上游声明的源 |
| 根目录 `.agents/skills/`、`.agents/doc-tools/` | 本仓库作为消费者使用的材料副本 |
| 根目录 `AGENTS.md`、`.agents/docs-config.json` | 本仓库的约定、文档范围和路径映射 |
| `README.md`、`docs/` | 本项目的使用说明、架构、开发和验收文档 |
| `.agents/notes/` | 本项目自身的决策依据 |

[项目检查器](../scripts/check_project.py) 比较可分发材料与本仓库副本的字节内容，防止两份规则分别演化。这个一致性约束只属于技能自身的开发项目；其他采用该技能的项目可以有自己的规则适配。

## 初始化与维护过程

[bootstrap.py](../agent-docs/scripts/bootstrap.py) 从现有目录识别文档位置，支持显式覆盖路径和语言。首次写入前检查全部目标；随后复制材料，给根目录及文档目录指令追加有界区块，并配置归档搜索排除。发生常规写入异常时尝试恢复原文件并删除新建文件；它不是进程中断或断电下的事务保证。已有配置时返回保留状态，不自动升级已有材料。

项目内 [docs.py](../.agents/doc-tools/docs.py) 的 `activate` 命令分四部分输出规则及必需引用。Agent 完整阅读后编写有证据支持的文档，运行结构检查，再提交具体语义复核记录给 `finish`。输出被截断时必须补读遗漏内容。仅有文件复制、路径清单或投递记录不能完成初始化。

`finish` 检查四部分投递摘要、项目内容及其证据文件、必要复核类别和结构错误。它没有会话标识，无法仅凭摘要判断投递是否发生在当前轮次，也不能验证 Agent 的理解；当轮阅读与内容准确性需要实际执行和审阅。

## 状态与归档

配置及正式文档随版本控制提交。激活、复核和完成记录保存在被忽略的 `.agents/doc-tools/.local/`，属于本机工作状态。历史试用目录和带本机绝对路径的旧验收文件同样不进入分发或版本控制。

决策记录采用 [Agent Notes 规则](../.agents/notes/README.md)。仍有未来指导价值的已实现记录保持事实准确；归档记录只作历史证据。`seal` 在验证现有摘要后加入新摘要；要检测内容和摘要被同时重写，还须通过 `--baseline` 与可信 Git 提交比较。只有本地哈希检查时不具备后一项保证。

## 检查范围

基础检查器扫描配置的文档目录、决策目录、项目技能和 `extra_docs`，排除冻结归档源及配置的排除项。链接检查覆盖常见行内链接和显式引用式链接的文件目标，不验证锚点、所有 Markdown 语法或文档站路由。

本项目检查器另外扫描分发包中的 Markdown 链接并比较源与副本。测试覆盖复制保护、生命周期错误、读取缺失或过期、归档篡改和这些自管理约束；它们不能替代文档语义复核。运行方法见 [开发与验证](development.md)。
